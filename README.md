# zcode-remote-client

ZCode 远程终端的跨平台客户端：一个包着原生外壳的完整功能浏览器，
支持 **iOS / Android / macOS / Windows**。

## 功能

- **完整功能浏览器**（`flutter_inappwebview`）：前进/后退/刷新、加载进度条、
  JS 弹窗（alert/confirm/prompt）、`window.open`、长按/右键菜单
  （复制 / 复制链接 / 分享 / 在浏览器打开）、下载外抛系统、文件上传、
  页面权限授予、非 http 链接交给系统、下拉刷新（移动端）、iOS 侧滑返回。
- **安全区适配**：全屏 WebView 包在 SafeArea 中，避开刘海、灵动岛和
  底部手势条；键盘弹出时页面自动收缩、工具栏浮到键盘上方。
- **保存远程地址**（设置页）：手动添加，备注可选——不填时依次尝试
  URL 的 `name` 参数 → 页面 `<title>` → `mid` 短码 → host 兜底，
  全部尽力而为、不做强制。相同 `mid` 再次录入会直接替换旧地址；
  加载失败时错误页提供「替换地址」入口。
- **悬浮玻璃 UI**（iOS 磨砂质感，半透明 + 模糊）：
  - 底部悬浮工具栏：导航 + 缩放（50%–250%，点百分比回到 100%）+
    页面操作菜单（复制链接/分享/复制全文/外部打开），可折叠成小把手。
  - 可拖拽悬浮球：点开设备切换面板；松手吸附屏幕左右边缘；闲置自动
    半透明；可从面板/设置隐藏，隐藏后留下贴边细把手，点击恢复。
- **多会话保活**：不同设备的页面用 IndexedStack 保持存活，切换不断连；
  可在切换面板里单独关闭某个会话释放内存。

## 运行

```bash
flutter pub get
flutter run -d macos     # 或 ios / android / windows 设备
```

各平台说明：

| 平台 | 说明 |
|---|---|
| iOS | 真机需配置签名；已声明相机/麦克风/相册用途描述 |
| Android | 已声明 INTERNET 权限，`adjustResize` 已配置 |
| macOS | 已添加 `network.client` 沙盒权限 |
| Windows | 需要系统装有 WebView2 Runtime（Win11 一般自带） |

## 注意

- 保存的地址包含 `sid`/`hash` 连接凭证，会原样存储在本机
  （`shared_preferences`），不要分享含有凭证的完整 URL。
- 地址过期/失效不做自动检测——打开报错后，在设置里编辑替换为新地址即可。
